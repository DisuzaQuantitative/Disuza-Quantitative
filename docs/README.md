# Disuza Quantitative — Public Documentation

> **Version 4.0.0 · Verified 2026-07-27**

**CURRENT:** Disuza Quantitative is a private, pre-deployment quantitative R&D initiative
building and validating rule-based systematic trading infrastructure. This
public reference separates verified current work from work in progress and
longer-term target architecture.

Disuza Quantitative does not present a live trading platform, publish current
investment performance, or offer an investment service.

Release-level status and non-claims are recorded in
[`PUBLIC_FACTS.yml`](../PUBLIC_FACTS.yml).

## Status vocabulary

Every capability statement in the v4 documentation uses one of these labels:

- **CURRENT** — verified as part of the present research programme.
- **IN PROGRESS** — active work that is not yet qualified as complete.
- **TARGET** — intended future capability. It is not deployed, qualified, or
  promised.

Target architecture must never be read as current operating capability.

## CURRENT — public research scope

The core research scope covers BTC and ETH perpetual markets and NQ and ES
index-futures markets. Optional CFD research is evaluated as a separate lane.
The primary design horizon is approximately 30 minutes to 4 hours.

This is a research scope, not a statement that these markets are currently
traded live.

## What is not included

The public reference excludes:

- strategy rules, signals, features, and parameters;
- private source code and private research records;
- datasets, provider entitlements, and lineage identifiers;
- trial counts, research verdicts, and performance metrics;
- account, counterparty, credential, and infrastructure details;
- operational thresholds, runbooks, incident records, and security boundaries.

## Publication rule

If a public statement cannot be supported as current, it must be labelled
**IN PROGRESS** or **TARGET**. If the evidence is not suitable for public
release, the statement is omitted.
